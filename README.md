# Text Similarity using Pretrained NLP Model

## Model Used

all-MiniLM-L6-v2

## Description

This Streamlit application compares three user-entered sentences using a free pretrained NLP model.

The application displays:

- Similarity Matrix
- Similarity Scores
- Bar Chart
- Heatmap
- PCA 2D Embedding Plot
- Paul's Critical Thinking Standards

## Requirements

Python

Streamlit

Sentence Transformers

Scikit-learn

Pandas

Matplotlib

Seaborn

Torch

## Run

streamlit run app.py
